# Vibe - Fishing Aquarium

**v3.0.2 · WoW: Forever · By Pepkilz**

A customizable, animated fishing aquarium for World of Warcraft: Forever. Catch fish, care for them, and build your collection.

## Features

- Unique fish with names, rarities, variants, personalities, and friendships.
- Fish feeding, happiness, hunger, and water-temperature survival.
- Fish encyclopedia, achievements, and a persistent collection.
- Animated aquarium with customizable decorations and performance settings.
- Fishing cast timer, bait reminders, and catch previews with an animated bobber-to-aquarium handoff.

## Install

Download the [latest release](https://github.com/peperonikiller/Vibe-Fishin---Aquarium/releases/latest) and extract the **`VibeFishin`** folder to `Interface/AddOns/`.

**WowUp:** **Get Addons → Install from URL** and paste this repository URL. The release ZIP includes a WoW Forever-specific TOC for WowUpHub.

## Commands

- `/vfish` — Options
- `/vfish journal` — Fish encyclopedia
- `/vfish feed` — Feed fish
- `/vfish on` / `/vfish off` — Fishing mode
